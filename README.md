# Kieron Edwards

This is my INFR3120 Assignment 1 website. It has four pages: home, about, projects, and contact.

## files

- `index.html` - home page
- `about.html` - about me
- `projects.html` - four projects
- `contact.html` - contact form
- `style.css` - styles
- `mobile.css`,`tablet.css`,`desktop.css` — styles for different screen sizes each

## layout
- Mobile: up to 600px. 1 column
- Tablet: 601–900px. 2 columns
- Desktop: 901px and wiper. always centered the page has far more room because its only 901px or wider.

## colors and gradients
Adobe Color theme: `#EF41F2`, `#0B1926`, `#3E5951`, `#736F6C`, `#595857`

There is a regular gradient in the header and angled gradients in the home panel and footer for differences like subtle ones.
